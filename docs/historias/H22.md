# H22 — Asignación de una rutina a un miembro

## Historia y criterios

Fuente: _HISTORIAS_USUARIO_GKDS_PROYECTO_2_IS_02_2026.pdf_, historia H22.

Frontend

1. El formulario solicita miembro asignado, nombre de rutina (3–80 caracteres), objetivo (3– 250), inicio y fin (fechas ISO locales, inicio no posterior a fin), y al menos un ejercicio de catálogo con día de la semana (1–7), series (1–10), repeticiones (1–100) y posición (1–50).
2. Al guardar muestra «Rutina asignada» y, en la siguiente carga de Mi rutina, se ve la rutina VIGENTE con fecha de asignación y fin.
3. Si el miembro no tiene membresía vigente o no está asignado al entrenador, la interfaz muestra el mensaje de error y no declara éxito.
   Backend
4. Rechaza una rutina sin ejercicios, con ejercicios fuera del catálogo, fechas inconsistentes o series/repeticiones fuera de rango (400 con field).
5. Conforme al supuesto de datos base (sección 4.4), el seed de Prisma crea las asignaciones TrainerMemberAssignment y solo ENTRENADOR con asignación ACTIVA puede crearla, y solo para miembro con membresía elegible; otro entrenador recibe 403/404, y un miembro recibe 403.
6. Para un mismo miembro solo queda una versión VIGENTE: una rutina nueva reemplaza la anterior mediante transición VIGENTE→REEMPLAZADA dentro de una transacción; no se pierden las versiones anteriores.

## Diseño backend e implementación

- **Módulo(s):** `routine-assignment`.
- **Endpoint(s)/componente(s):** `POST /api/v1/training-routines/trainers/me/members/:memberId/routines/versions; GET /api/v1/exercises`.
- **Modelos Prisma implicados:** `TrainingRoutine, RoutineExercise, Exercise, TrainerMemberAssignment`. Se declaran en el esquema único `prisma/schema.prisma`; no se mantiene un schema independiente por historia.
- **Datos demo:** seed de historia `prisma/seeds/h22.seed.ts`; utiliza fixtures compartidos del grupo `core + routines` para conservar coherencia entre historias y permitir repetir el seed.
- **Pruebas asociadas:** `Pruebas de módulo y validación descritas en el catálogo del backend.`.

## Archivos fuente de referencia
